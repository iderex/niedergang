# Code of conduct

## Where this applies

The issue tracker, pull requests, commit messages and anything else that happens
in or about this repository.

## What is expected

Argue with the work. A model choice, a number, a citation or a design can be
taken apart as hard as the evidence allows, and somebody who shows that a result
is wrong has done the project a favour whatever tone they used to do it.

Do not argue with the person. Insults, harassment, sexualised attention,
sustained disruption, publishing somebody's private information, and hostility
directed at who somebody is rather than at what they wrote are all out of
bounds, and none of them become acceptable because the technical point
underneath was correct.

Two things this project cares about more than most. Do not overstate what you
know: a claim presented as measured when it was assumed wastes the time of
everybody who trusts it, and in a tool that computes a safety number it does
more than waste time. And do not press somebody to soften a negative result. A
finding that something does not work, does not reproduce or was never checked
stays in the words that say so.

## Reporting

Reports go to the maintainer privately. This repository's only private channel
today is GitHub's private vulnerability reporting, on the Security tab, and it
is fine to use it for a conduct report even though its name says otherwise. The
maintainer's GitHub profile also carries a contact address.

That reuse is a workaround and it is written here rather than hidden: a
repository with one maintainer and no separate contact address has nowhere else
to put this, and a report about the maintainer has nowhere private to go at all.
If that case arises, GitHub's own abuse reporting is the route that does not
pass through the person being reported.

A report is read by the maintainer and by nobody else, and it is not repeated to
the person it is about beyond what answering it requires.

## What happens

What is warranted, from a private word to being blocked from the repository.
There is no ladder of fixed steps here, because a fixed ladder invites an
argument about which rung a thing sits on rather than about whether it happened.

## Provenance

This is a short document written for this project rather than an adaptation of
the Contributor Covenant. That is deliberate: the Covenant is offered under a
licence with its own attribution terms, and this repository has not yet decided
its own licence, so borrowing a text now would settle a small question in the
middle of an open larger one. If the project later adopts a standard text, this
file is replaced by it rather than being edited into a hybrid.
